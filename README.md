# 초파리 CNS 개발 기록

Notion에서 내보낸 개발 기록 및 시각 신호 검증 보고서의 GitHub Pages 정적 사이트입니다.

- `index.html`: 개발 기록 (기본 페이지)
- `report.html`: 시각 신호 검증 보고서
- `assets/`: 로컬 이미지 2개

## 배포
1. 이 폴더의 **내용물**을 GitHub 저장소 루트에 업로드합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. Branch를 `main`, 폴더를 `/(root)`로 설정하고 Save합니다.
4. 게시된 GitHub Pages 주소로 접속합니다.

노션의 원본 내용을 자동 동기화하는 구성은 아닙니다. 수정한 HTML을 다시 커밋해야 반영됩니다.
